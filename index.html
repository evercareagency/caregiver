Add EverCare to Home Screen

On iPhone, you add this from Safari — there is no one-tap Install button. Follow these easy steps:

  1. Tap Share — the square with an arrow pointing up (usually at the bottom of Safari).
  2. Tap “Add to Home Screen” — scroll the list if you don’t see it right away.
  3. Tap “Add” in the top right. Done — EverCare appears on your home screen.

Using Android Chrome? If Install didn’t pop up, open the browser menu (⋮) → Install app or Add to Home Screen.
